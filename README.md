# Ansh Raghav – Portfolio

A simple, responsive personal portfolio website built with plain HTML, CSS and JavaScript. It introduces me, lists my skills, and showcases my projects.

## About me

I'm Ansh Raghav, a student at KIET Deemed to be University, Ghaziabad. I enjoy building clean, useful things for the web and solving problems in C++.

## Features

- Clean, minimal design with a hero section, About, Skills, Projects and Contact sections
- Responsive layout that works on phones, tablets and desktops
- Automatic light and dark mode based on your device settings
- Nav link highlights the section you are viewing
- Smooth scrolling and a short entrance animation (respects reduced-motion settings)
- No frameworks or build tools needed

## Tech stack

- HTML5
- CSS3
- JavaScript (vanilla)

## Project structure

```
.
├── index.html   # Page structure and content
├── style.css    # Styling, colors, layout and dark mode
└── script.js    # Footer year and active nav link
```

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/anshraghav0205/<repo-name>.git
   ```
2. Open the folder and double-click `index.html`, or open it in your browser.

## Deploy with GitHub Pages

1. Push the files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Source**, choose the `main` branch and the `/ (root)` folder, then save.
4. Your site will be live at `https://anshraghav0205.github.io/<repo-name>/` after a minute or two.
